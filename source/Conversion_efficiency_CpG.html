The Ideal Scenario

In DNA methylation analysis, the goal is to differentiate between methylated and unmethylated cytosines. The process works by converting unmethylated cytosines to uracil (which is read as thymine during sequencing), while methylated cytosines remain unchanged. Unmethylated Control (Unmethylated Lambda DNA): This is a DNA sample with no methylated cytosines. After treatment, all unmethylated cytosines should be converted. The conversion efficiency is a measure of how successfully this process occurred. An ideal conversion efficiency would be 100%, but values of 99% or higher are considered excellent. A low conversion efficiency means some unmethylated cytosines weren’t converted, leading to an overestimation of methylation in your samples. Methylated Control (CpG-methylated pUC19 DNA): This is a DNA sample where all cytosines (specifically in a CpG context) have been methylated, typically using an enzyme. After bisulfite treatment, these methylated cytosines should not be converted. The methylation percentage of this control should be close to 100% (e.g., 95-98%). This percentage measures the stability of the methylated cytosines and the effectiveness of the bisulfite treatment in leaving them untouched. Why They Aren’t Identical:While the two values are related and both reflect the quality of the conversion, they are not direct mirrors of each other for several key reasons: Enzymatic vs. Chemical Efficiency: A methylated control is usually created with an enzyme, and enzymatic methylation is rarely 100% complete. For example, some commercially available methylated controls are stated to be 96-98% methylated. An unmethylated control, like lambda DNA, is naturally unmethylated, so it starts with a 0% methylation baseline. The conversion efficiency for the unmethylated control is a measure of the chemical reaction’s success, while the methylation percentage of the methylated control is a measure of both the chemical reaction and the initial enzymatic methylation. Bisulfite Conversion Limitations: The bisulfite conversion process itself is harsh and can cause some DNA degradation. This can also lead to a slight overestimation of methylation in the unmethylated control, even if conversion is very high. It’s common to see a very small methylation percentage (e.g., <1%) in an unmethylated control, which corresponds to a conversion efficiency of >99%. Different Metrics, Same Goal: In essence, the unmethylated control is used to measure the efficiency of conversion, while the methylated control is used to measure the stability of methylated sites during the conversion process. They are both essential quality control checks for the overall methylation analysis workflow. So, while a high methylation percentage in the methylated control and a high conversion efficiency in the unmethylated control are both indicators of a successful experiment, they are measuring slightly different aspects of the process and are not expected to be perfectly complementary (e.g., 98% methylation and 2% conversion inefficiency).

# A function to read a single large file, calculate summaries, and free up memory.
process_methylation_file <- function(file_path, context_name) {
  # Read the bedGraph file using fread, which is very efficient for large files
  data <- fread(file_path, header = FALSE, col.names = c("chrom", "start", "end", "percent_methylation", "methylated_reads", "unmethylated_reads"))
  
  # Add the context column and remove missing values
  data$context <- context_name
  data <- na.omit(data)
  
  # Group by chromosome and context to calculate summary statistics
  summary_stats <- data %>%
    group_by(chrom, context) %>%
    summarise(
      total_reads = sum(methylated_reads + unmethylated_reads),
      mean_meth = mean(percent_methylation, na.rm = TRUE),
      median_meth = median(percent_methylation, na.rm = TRUE),
      sd_meth = sd(percent_methylation, na.rm = TRUE),
      .groups = "drop"
    )
  
  # Explicitly remove the large raw data from memory and run garbage collection
  rm(data)
  gc()
  
  return(summary_stats)
}

Making scatter and Methylation Bias Plots

Plots that require plotting every single read, such as the scatter plots and methylation bias plots (pUC19_scatter, lambda_scatter, chrM_scatter, etc.), are still memory-intensive. For these, the best practice is to load one file at a time, generate the plot, save it, and then clear the data from memory immediately. This ensures that you never have multiple large datasets in memory at once.

# Function to read, plot, and clean up for a single chromosome
plot_single_chromosome <- function(file_path, chrom_name, title, subtitle, x_label, y_label) {
  # Read the specific chromosome data from the large file
  data <- fread(file_path, header = FALSE, col.names = c("chrom", "start", "end", "percent_methylation", "methylated_reads", "unmethylated_reads"))
  
  # Clean up and filter the data for the target chromosome
  data <- na.omit(data)
  data$chrom <- gsub("genome_hic_", "", data$chrom)
  data$chrom <- gsub("_RagTag", "", data$chrom)
  data_subset <- data %>% filter(chrom == chrom_name)
  
  # Create the plot
  plot <- ggplot(data_subset, aes(x = start, y = percent_methylation)) +
    geom_point(alpha = 0.6, size = 2) +
    labs(title = title, subtitle = subtitle, x = x_label, y = y_label) +
    theme_ipsum()
  
  # Save the plot
  ggsave(paste0("~/methylation/Methyl47625/figures/", gsub(" ", "_", title), ".png"), plot = plot, width = 10, height = 6, dpi = 300)
  
  # Clean up and free memory
  rm(data, data_subset)
  gc()
}

Conversion Efficiency Calculation

The frequency of CpG methylation in the λ-bacteriophage genome provides an estimate of the conversion efficiency. This is because the λ-bacteriophage genome is grown in methylase-negative Escherichia coli, which cannot methylate cytosines in a CpG context. For example, if the observed CpG methylation frequency in the λ-bacteriophage is 0.2%, the cytosine-to-thymine conversion in the sample is estimated to be 99.8% efficient.

(Singer 2019: “A practical guide to the Measurement and analyses of DNA methylation”)

NEB Tech advice on using CHH and CHG methylation to supplement controls and chrM for testing conversion efficiency: “If I wanted to judge the conversion efficiency, I would simply look at the lowest methylation you see anywhere. Often it is enough to just look at the methylation levels in a non-CG context (in mammalian systems); otherwise, some people look at reads from the MT, or within CpG islands. If you see a general methylation of 0.3% in a non-CG context, then your conversion efficiency must have been at least 99.7%.”

Extracting and saving data for control

This code snippet processes each large bedGraph file sequentially to avoid memory issues. It identifies the control chromosomes (“OR482510.1”, “plasmid_puc19c”, and “phage_lambda”) and writes the data for each one into a separate, dedicated CSV file.

# Define the file paths for the three large bedGraph files
file_paths <- c(
  "/home/cgumbi/methylation/refcombined/ABLG-47625_CpG.bedGraph",
  "/home/cgumbi/methylation/refcombined/ABLG-47625_CHG.bedGraph",
  "/home/cgumbi/methylation/refcombined/ABLG-47625_CHH.bedGraph"
)

# A list of the chromosomes we want to subset
chromosomes_to_subset <- c("OR482510.1", "plasmid_puc19c", "phage_lambda")

# Loop through each large bedGraph file
for (file_path in file_paths) {
  # Determine the context (CpG, CHG, or CHH) from the file name
  context <- sub(".bedGraph", "", basename(file_path))
  context <- sub("ABLG-47625_", "", context)
  cat(paste0("Processing ", context, " data...\n"))

  # Read the large file using fread for maximum efficiency
  raw_data <- fread(file_path, header = FALSE, 
                      col.names = c("chrom", "start", "end", "percent_methylation", "methylated_reads", "unmethylated_reads"))

  # Clean up chromosome names if this is the CpG file (based on previous scripts)
  if (context == "CpG") {
    raw_data$chrom <- gsub("genome_hic_", "", raw_data$chrom)
    raw_data$chrom <- gsub("_RagTag", "", raw_data$chrom)
  }

  # Filter the raw data to only keep the chromosomes of interest
  subset_data <- raw_data %>% filter(chrom %in% chromosomes_to_subset)
  
  # Check if any data was found
  if (nrow(subset_data) == 0) {
    cat("No data found for control chromosomes in", context, "file.\n")
    # Clean up and continue to the next file
    rm(raw_data, subset_data)
    gc()
    next
  }

  # Split the subsetted data into separate data frames based on chromosome name
  split_by_chrom <- split(subset_data, subset_data$chrom)

  # Loop through the split data frames and save each one to a CSV
  for (chrom_name in names(split_by_chrom)) {
    df_to_save <- split_by_chrom[[chrom_name]]
    
    # Create a clean file name
    file_name <- paste0(context, "_", chrom_name, ".csv")
    full_path <- file.path("~/methylation/Methyl47625/tables/", file_name)

    # Write the data frame to the specified CSV file
    write.csv(df_to_save, full_path, row.names = FALSE)
    cat(paste0("Saved data for ", chrom_name, " (", context, ") to ", full_path, "\n"))
  }

  # Explicitly remove the large raw data and the subsetted data to free up memory
  rm(raw_data, subset_data, split_by_chrom)
  gc()
}

Express methylation as weighted averages

If you simply average percent methylation across all CpGs, low-coverage sites weigh the same as high-coverage ones. A better approach is a coverage-weighted mean

# Using `trimws` to remove any leading/trailing whitespace.
names(lambda_covarage) <- trimws(names(puc19_covarage))
# Now we can join the dataframes.
combined_control_data <- bind_rows(lambda_covarage, puc19_covarage, mito_covarage)
#write the combined dataframe to a new file
write.csv(combined_control_data, "~/methylation/Methyl47625/tables/combined_cpg_control_data.csv", row.names = FALSE)

#Calculate the weighted average methylation percentage for each chromosome.
# This is a more robust metric than a simple average of percentages, as it
# accounts for the total number of reads at each site. We group the data
# by chromosome and then summarize the total methylated and total read depth.
weighted_methylation_by_chrom <- combined_control_data %>%
  group_by(chrom) %>%
  summarise(
    total_methylated_reads = sum(methylated_reads),
    total_read_depth = sum(read_depth),
    weighted_percent_methylation = (sum(methylated_reads) / sum(read_depth)) * 100,
    .groups = 'drop' # This drops the grouping after summarising
  )

# Print the resulting summary table.
print(weighted_methylation_by_chrom)
## # A tibble: 3 × 4
##   chrom          total_methylated_reads total_read_depth weighted_percent_meth…¹
##   <chr>                           <int>            <int>                   <dbl>
## 1 OR482510.1                         13              174                    7.47
## 2 phage_lambda                       72             2052                    3.51
## 3 plasmid_puc19c                    233              240                   97.1 
## # ℹ abbreviated name: ¹​weighted_percent_methylation
# You can also write the combined dataframe to a new file, if needed.
# For example, to save it as a new CSV file:
write.csv(weighted_methylation_by_chrom, "~/methylation/Methyl47625/tables/weighted_methylation_pecentage_cpg_data.csv", row.names = FALSE)
